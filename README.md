# 🏥 Hospital Management System

A comprehensive **Hospital Management System** built with **Python**, **Django**, **SQLite**, **HTML5**, **CSS3**, and **Bootstrap 5**. The application centralizes hospital services by enabling appointment booking, doctor and patient management, billing, emergency care, pharmacy, diagnostic services, and other healthcare functionalities through a clean and intuitive interface.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/vishal-Dhule/Hospital-Management-System.git
```

## 📥 Download Project

If you'd like to download the complete source code, you can use the Google Drive link below:

🔗 **Google Drive:**  
https://drive.google.com/file/d/1X7WlbkcdqvqSfBfXhD6WuhCtAhtHQTy3/view?usp=sharing

> **Note:** The project includes the source code, templates, static files, screenshots, and other required project files.

### 2. Open the project

```bash
cd hospital-management-system
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply migrations

```bash
python manage.py migrate
```

### 7. Run the server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
